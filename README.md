# Telegram Habit Bot browser demo
An English simulation of the existing Telegram bot: /today starts or resets five habits, buttons toggle completion, and summary feedback uses the original 0–1, 2–3, 4–5 thresholds. No reminders, streaks or history are implied. Browser localStorage persists the visitor checklist; reset clears it. No Telegram/Redis credentials, personal data, backend calls or production bot connections are included. The original TypeScript project is unchanged.

The browser demo includes a rolling seven-day tracker: six clearly labeled sample historical counts and today’s live checklist count. This is a demo extension, not historical data from the Telegram bot.
